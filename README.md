# 🍔 Şahane Burger - Restaurant Website

A modern, responsive, and visually appealing restaurant website built with _React.js_. This project showcases the perfect blend of technical front-end development and creative graphic design.

## 🎨 Design & Branding

Unlike standard templates, this project features custom design elements:

- _Branding:_ Visual identity designed using _Adobe Illustrator_.
- _Image Assets:_ High-quality imagery edited and optimized using _Adobe Photoshop_.
- _UI/UX:_ Focused on a clean, appetizing, and user-friendly experience.

## 🚀 Technologies Used

- _Front-end:_ React.js, HTML5, CSS3, JavaScript (ES6+).
- _Styling:_ Responsive Design (Mobile First).
- _Tools:_ Git, GitHub, VS Code.

## 🛠️ Features

- ✨ Dynamic and responsive layout.
- 🍔 Interactive menu display.
- 📱 Fully optimized for mobile, tablet, and desktop.
- 🎨 Custom-designed graphics for a unique brand feel.
